DNA Transcription and Translation using Biopython

Description
This project takes a DNA sequence as input and uses Biopython to perform:
- DNA transcription into RNA
- DNA translation into a protein sequence

Biological Process
DNA → RNA → Protein

Transcription
DNA is transcribed into RNA.
Example:
DNA:
ATGGCTAAA
RNA:
AUGGCUAAA

Translation
The RNA sequence is translated into a protein sequence using codons.
Example:
AUG → M  
GCU → A  
AAA → K
Protein:
MAK

Technologies Used
- Python
- Biopython
